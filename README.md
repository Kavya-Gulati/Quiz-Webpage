# Quiz Webpage

A simple quiz webpage made using **HTML, CSS, and beginner-level JavaScript**. The quiz contains multiple-choice questions and calculates the user's score after submission.

## Features

- 10 multiple-choice questions
- Simple and clean user interface
- Score calculation using JavaScript
- Correct answers are highlighted in **green**
- Incorrect answers are highlighted in **red**
- Responsive design for different screen sizes
- Works on phones, tablets, laptops, and desktops

## Technologies Used

- **HTML** – Used to create the structure of the webpage and quiz form.
- **CSS** – Used for styling, layout, and responsive design.
- **JavaScript** – Used to calculate the score and highlight correct and incorrect answers.

## Responsive Design

The webpage uses responsive CSS properties so that the quiz layout adjusts according to the screen size. It is designed to work properly on:

- 📱 Mobile phones
- 📱 Tablets
- 🖥️ Desktop screens

## How It Works

1. Select an answer for each question.
2. Click the **Submit** button.
3. JavaScript checks the selected answers.
4. The score is calculated based on the number of correct answers.
5. Correct answers are highlighted in green and incorrect answers are highlighted in red.
